Natural Language Processing (NLP) rests on a hierarchy of linguistic abstractions that decompose language into analyzable units and structures. Tokenization segments raw text into discrete units—words, subwords, or characters—serving as the fundamental input representation for all downstream processing. Part-of-speech (POS) tagging assigns grammatical categories (e.g., noun, verb, adjective) to each token, capturing morphosyntactic properties essential for disambiguation and shallow analysis. Syntactic parsing constructs hierarchical tree structures (constituency or dependency) that encode grammatical relationships among tokens, revealing phrase structure and grammatical roles. Semantic role labeling (SRL) goes beyond syntax to identify predicate-argument structures, assigning roles such as Agent, Patient, or Location to constituents relative to a predicate, thereby modeling event semantics.

Classical NLP tasks operationalize these abstractions to solve concrete problems. Named entity recognition (NER) identifies and classifies named entities (e.g., persons, organizations, locations) within text, grounding language in real-world referents. Dependency parsing explicitly models binary grammatical relations (e.g., *nsubj*, *dobj*) between head and dependent words, providing a compact, directed representation of sentence structure. Coreference resolution links noun phrases that refer to the same underlying entity across discourse, enabling coherent interpretation of pronouns and definite descriptions. These tasks collectively formalize the linguistic knowledge required for machines to interpret human language at multiple levels of granularity.

These classical components constitute the conceptual bedrock for modern deep learning–based NLP. While neural models—particularly transformer architectures—learn representations end-to-end without explicit rule-based modules, they implicitly recapitulate and generalize these foundational abstractions. For instance, attention mechanisms in transformers exhibit patterns reminiscent of syntactic dependencies; contextualized embeddings encode POS and semantic role information; and pretraining objectives encourage models to learn entity boundaries and coreferential constraints. Thus, classical NLP provides not only historical context but also interpretable scaffolding for understanding what modern models learn, how they fail, and how to design more robust, linguistically informed architectures.
