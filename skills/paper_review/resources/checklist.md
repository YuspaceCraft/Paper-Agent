# Paper Review Checklist

## Methodology Soundness
- [ ] Problem clearly defined
- [ ] Approach well-motivated
- [ ] Baselines are SOTA (not cherry-picked weak baselines)
- [ ] Ablation studies cover key design choices
- [ ] Hyperparameter settings reported
- [ ] Computational cost discussed

## Experimental Rigor
- [ ] Multiple datasets used
- [ ] Metrics appropriate for the task
- [ ] Statistical significance tests reported
- [ ] Error bars / standard deviation shown
- [ ] Code/data publicly available

## Claims & Evidence
- [ ] Main claims supported by experiments
- [ ] Limitations honestly discussed
- [ ] Performance improvement over baselines is meaningful
- [ ] No over-claiming in abstract/conclusion

## Reproducibility
- [ ] Architecture clearly described
- [ ] Training procedure documented
- [ ] Dataset preprocessing described
- [ ] Random seeds reported
